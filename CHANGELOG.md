# Changelog

## v4.0 — 2026-11-14

- Clarify that Travel Companion is a callable travel skill for each user's existing Agent, not a standalone Agent, persona package, shared-memory service or cross-platform migration system.
- Protect the host Agent's identity and relationship.
- Support chronological, structural, associative and hybrid entry paths; allow users to switch paths at any time.
- Treat planning paths as temporary interaction approaches, not personality labels.
- Separate the idea pool from selected, booked, paid and experienced trip states.
- Preserve decision history, evidence, privacy boundaries and truthful capability limits.

## Project charter update — 2026-11-14

- Publish four enduring principles: Respect Travel, Respect the Agent, Respect Memory and Respect People.
- Make recommendation independence explicit: no paid placement, affiliate influence, sponsored ranking or sales-funnel use.
- Clarify the complete travel cycle: planning, on-trip assistance, optional post-trip reflection and a traveler-controlled personal journal.
- Clarify contributor rights and separate permission for commercial reuse of third-party contributions.
- Record the possible six-month free complete-trip allowance as a future product direction only; it is not implemented.
- Leave the final repository license pending rather than publishing a license before business-use boundaries are settled.
